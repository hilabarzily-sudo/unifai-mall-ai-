# PWA Icons

Generate icons using a tool like [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator):

```bash
npx pwa-asset-generator logo.png ./public/icons --icon-only --favicon
```

Required icon sizes:
- 72x72
- 96x96
- 128x128
- 144x144
- 152x152
- 192x192
- 384x384
- 512x512

Place your logo.png file in the root directory and run the command above to generate all required sizes.
