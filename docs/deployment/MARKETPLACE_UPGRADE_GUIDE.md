## 📋 הוראות התקנה

### שלב 1: הרצת המיגריישן ב-Supabase

1. היכנס ל-Supabase Dashboard: https://supabase.com/dashboard
2. בחר את הפרויקט שלך
3. לך ל-**SQL Editor** (בתפריט הצד)
4. פתח את הקובץ `scripts/migration-enhance-tools.sql`
5. העתק את כל התוכן ו**הדבק בעורך**
6. לחץ על **RUN** (או Ctrl+Enter)
7. וודא שהמיגריישן רץ ללא שגיאות

**מה המיגריישן עושה?**
- מוסיף עמודות חדשות לטבלת `tools`
- יוצר טבלה `tool_reviews` עבור ביקורות
- יוצר טבלה `tool_analytics` עבור מעקב צפיות
- מוסיף triggers אוטומטיים לעדכון דירוגים
- מגדיר RLS policies לאבטחה

### שלב 2: עדכון תוכן הכלים

הרץ את הסקריפט לעדכון הכלים עם תוכן עשיר:

```bash
node scripts/populateToolsData.js
```

**מה הסקריפט עושה?**
- עובר על כל 114 הכלים במסד
- מוסיף תוכן מעודכן ל-8 כלים פופולריים (ChatGPT, Claude, Midjourney, וכו')
- ממלא שאר הכלים עם תוכן ברירת מחדל
- מציג progress bar וסיכום

**פלט צפוי:**
```
🚀 מתחיל עדכון תוכן הכלים...

📊 נמצאו 114 כלים לעדכון

✅ עודכן: ChatGPT
✅ עודכן: Claude
✅ עודכן: Midjourney
...

📊 סיכום:
✅ עודכנו: 114 כלים
❌ נכשלו: 0 כלים
```

### שלב 3: בדיקת המסד

וודא שהכל עובד:

```bash
node scripts/checkDatabase.js
```

זה יציג את כל הטבלאות ומספר הרשומות בכל אחת.

## 🐛 פתרון בעיות נפוצות

### שגיאה: "Missing Supabase environment variables"
**פתרון:** וודא שיש לך קובץ `.env` עם:
```
VITE_SUPABASE_URL=your-project-url
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### שגיאה במיגריישן: "permission denied"
**פתרון:** וודא שאתה מחובר כ-postgres user ב-Supabase SQL Editor

### הפילטרים לא עובדים
**פתרון:** בדוק שהכלים במסד כוללים את השדות:
- `category` (name_he)
- `is_free`
- `rating`

### הכלים הדומים לא מופיעים
**פתרון:** וודא שמעבירים את `allTools` ל-ToolPage component ב-`App_New.jsx`:
```jsx
<ToolPage
  tool={selectedTool}
  allTools={allTools}  // ← חשוב!
  onOpenTool={handleOpenTool}
  ...
/>
```

## 🚀 צעדים הבאים (אופציונלי)

### 1. חיבור מערכת הדירוגים ל-API
עדכן את `handleRateSubmit` ב-`04-ToolPage.jsx`:
```javascript
const handleRateSubmit = async () => {
  if (userRating > 0 && user) {
    const { error } = await reviewsService.upsertReview(
      user.id,
      toolData.id,
      userRating
    );
    if (!error) {
      alert(`דירוג של ${userRating} כוכבים נשמר!`);
      setShowRatingDialog(false);
      // Refresh tool data
    }
  }
};
```

### 2. הוספת כלים נוספים
ערוך את `scripts/populateToolsData.js` והוסף כלים ל-`toolEnhancements` object.

### 3. Analytics ו-Tracking
השתמש ב-`tool_analytics` table למעקב:
```javascript
// Track tool view
await supabase
  .from('tool_analytics')
  .insert({
    tool_id: toolId,
    user_id: userId,
    event_type: 'view'
  });
```
