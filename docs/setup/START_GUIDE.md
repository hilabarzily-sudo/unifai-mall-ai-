## 🛠️ פתרון בעיות:

### אם הסקריפט נתקע על node_modules:
```bash
rmdir /s /q node_modules
del package-lock.json
npm install
```

### אם יש בעיה עם .env:
הסקריפט יוצר אותו אוטומטית! אבל אם צריך ידנית:
```
VITE_SUPABASE_URL=https://qdcovbyzaapgfamcplrt.supabase.co
VITE_SUPABASE_ANON_KEY=[המפתח שלך]
```

### אם הפורט תפוס:
הסקריפט יזהה ויציע פורט חלופי אוטומטית!
