# UnifAI Mall - Frontend

This is the new organized frontend structure. The original files remain in the root directory.

## Structure

```
frontend/
├── src/
│   ├── components/
│   │   ├── screens/         # 14 Full screen components
│   │   ├── ui/              # Reusable UI components
│   │   └── layout/          # Layout components
│   ├── services/            # API services
│   ├── hooks/               # Custom React hooks
│   ├── utils/               # Utility functions
│   ├── lib/                 # Third-party configurations
│   ├── App.jsx              # Main application
│   ├── main.jsx             # Entry point
│   └── index.css            # Global styles
```

## Usage

This structure provides better organization for large-scale applications while maintaining backward compatibility with the original structure.
